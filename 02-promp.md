1. Eres el encargado de diseñar una estructura XML para administrar una librería en línea.
2. Crea un archivo XML dentro de library/apps/services/soap/library.xml que contenga una lista de libros obtenidos de la base de datos de postgres de acuerdo al esquema disponible en data/schema.sql con los datos en data/seed.sql
3. EL XML debe tener una estructura orientada a libros  ISBN, título, autor, año de publicación, género, precio, stock, formato, imágenes y conceptos definidos por libro
4. EL diseño debe estar en idioma ingles
